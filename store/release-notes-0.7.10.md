实时画面这次是重构级的优化。

- **二进制帧通道**：manifest 改用 `stdio-framed` 传输并声明 `host.binary`，每帧直接发原始 JPEG，不再经过 base64（省约 25% 体积）与 JSON 编解码
- **Worker 解码**：画布交给 Worker 的 OffscreenCanvas，解码与绘制全部离开主线程（实测主线程解码次数为 0）
- **滚动降质**：滚动时 JPEG 质量降到 60 换帧率，停手 350ms 自动恢复到 85
- **1:1 采集**：视口 = 面板尺寸、按系统 DPR 栅格化，画面不再被放大，文字清晰度接近浏览器
- 修复：Worker 画完一帧后不再接管排队帧导致的"只画第一帧"问题
- 测试工具（协议冒烟、预设体检）同步支持 framed 传输

实测（dev host）：收到 38.3 fps、实际画出 30.3 fps，主线程解码 0 次。

仅 Windows（依赖 WebView2），要求 DBX >= 0.6.0。
