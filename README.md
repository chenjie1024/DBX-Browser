# Browser · 在 DBX 里直接读网页

DBX 是数据库工具，但查文档、追小说、刷小红书时总要切到浏览器。这个插件把「打开网址 → 抓正文 →
排成好读的版式」整条链路搬进 DBX：一个工作台标签页里完成，不用离开数据库界面。

遇到必须登录、必须跑 JavaScript 的站点（小红书、抖音、B 站），可以切到**实时页面**：插件内直接渲染
真实网页，鼠标键盘照常可用，能登录、能评论；需要声音和视频时，还能一键拉起系统的 Chrome / Edge 窗口。

## 安装

### 方式一：从 GitHub Release 安装（推荐，当前可用）

官方商店审核期间，用这个方式安装：

1. 打开 [Releases](https://github.com/chenjie1024/DBX-Browser/releases)，下载最新版的
   `com.dbx.webview-<版本>-windows-x64.dbxp`。
2. 在 DBX 打开**插件中心 → 设置**，勾选 **「允许安装未签名开发包」**。
   > 未签名的包默认不允许安装，这个开关就是为此准备的；它不会放宽官方商店的校验。
3. 回到插件中心，用「安装本地插件 / 从文件安装」选择刚下载的 `.dbxp`。
4. 装好后工具栏会出现 **Browser** 按钮；也可以从命令面板搜索 `Browser` 打开。

### 方式二：官方商店

已向 DBX 官方商店提交（[dbx-store PR](https://github.com/t8y2/dbx-store/pulls/380)），审核签名后
可在插件中心直接搜索安装。届时无需开启「允许安装未签名开发包」。

### 方式三：从源码构建（开发者）

需要 Node.js 22+、Rust 工具链、以及 `@dbx-app/plugin-cli`：

```bash
npm install -g @dbx-app/plugin-cli
git clone https://github.com/chenjie1024/DBX-Browser.git
cd DBX-Browser
dbx-plugin package .
# 产物在 dist/：.dbxp 安装包 + .artifact.json 元数据
```

前端调试可以不装 DBX：

```bash
dbx-plugin dev --path . --port 5190
```

### 升级与卸载

- **升级**：下载新版本 `.dbxp`，覆盖安装即可（同 ID 会替换旧版本）。
- **卸载**：插件中心 → 该插件 → 卸载。本地小说正文与设置保存在插件数据目录，卸载会一并清理。

## 快速上手

1. **打开工作台**：工具栏点 **Browser**（或命令面板搜 `Browser`）。
2. **输入网址**：地址栏输入 `https://…` 回车；也可以直接输入关键词，会走当前站点的站内搜索，
   没有站内搜索就用必应。
3. **选渲染方式**：地址栏右侧下拉用 **阅读模式**（默认，抓正文重排）或 **整页模式**（保留原版式）。
4. **调样式**：右上角 **设置** → 字体、字号、行高、页宽、配色，改完立即生效。
5. **收藏与历史**：工具栏 **收藏此页**；侧栏 **书签** / **历史** 可回看。

## 四种渲染方式

地址栏右侧的下拉和工具栏按钮决定用哪种方式看页面：

| 方式 | 入口 | 适合 | 说明 |
|---|---|---|---|
| **阅读模式** | 模式 = 阅读模式 | 文章、新闻、小说章节、文档 | 服务端抓取 + 净化，只留正文；自动识别章节目录与上一章/下一章 |
| **整页模式** | 模式 = 整页模式 | 想保留原页面结构 | 同样是抓取，但不做正文裁剪 |
| **实时页面** | 工具栏 **实时页面** | 小红书、抖音、B 站等强 JS 站点 | 插件内渲染真实网页，可登录/点击/输入/滚动；**没有声音** |
| **浏览器窗口** | 工具栏 **浏览器打开** | 需要视频、音频、扩展 | 用系统 Chrome/Edge 打开，功能最完整，但不在 DBX 面板里 |

> 阅读模式和整页模式都受「服务端能不能拿到 HTML」限制：需要登录、强验证码的站点会失败，
> 这时请用**实时页面**或**浏览器窗口**。

## 操作详解

### 标签页与地址栏

- 侧栏 **标签页** 里可以开多个标签，列表底部点 `＋ 新建` 开新标签。
- 工具栏：**后退 / 前进 / 刷新**，地址栏右侧可**复制地址**。
- 小说章节页会自动识别目录，地址栏旁出现 **目录** 按钮，一键跳回该书目录。

### 阅读模式

- 自动清理导航、广告、评论区、弹窗，只保留正文与图片。
- **图片**由插件代理加载（处理防盗链），不会因为 Referer 校验变成破图。
- **章节目录识别**：不依赖 class 名，而是找「一组 URL 形状相同、标题互不相同的链接」，
  小说站门槛 5 条、其它站点 15 条，避免把「相关阅读」误判成目录。
- **上一章 / 下一章**：识别页面里的翻页链接；章节页底部会显示「第 n / m 章」。
- 首页、列表页这类「只有链接、没有正文」的页面会明确提示，而不是把一屏链接倒给你。

### 站点预设

侧栏 **站点预设** 决定「这个站点怎么抓、用哪种排版」。内置 12 条：

> 小说站（混淆类名）、通用小说站、小红书、哔哩哔哩、抖音、红果短剧、豆瓣、论坛与社区、
> 中文资讯、技术博客、维基百科、通用网页

- **自动识别**：按域名自动匹配；可以在列表里手动指定某条规则套用到当前页面。
- **新建**：`＋ 新建`，填名称、分类、域名（逗号分隔）、正文选择器、要删除的选择器、站内搜索模板、
  渲染模式。保存后立即生效。
- **域名标签右键菜单**：
  - **修改**：自定义预设就地改名；内置预设改不了本体，会「屏蔽旧域名 + 按原选择器复制一条规则到新域名」。
  - **删除**：先弹出「确认删除 xxx？」再点一次才生效。自定义预设直接从规则里移除；
    内置预设只是记入屏蔽列表，域名变成灰色删除线，**右键可恢复**。
- 规则保存在插件数据目录，重装/升级不会丢。

### 实时页面

工具栏 **实时页面** → 插件内开始渲染真实网页（首次打开需要几秒）。

- **鼠标键盘**：点击、输入（含中文输入法）、滚动、快捷键都转发给页面，可以正常登录、点赞、发评论。
- **登录态**：保存在插件自己的浏览器 profile 里，下次打开仍是登录状态。
- **退出**：右上角 **退出实时**。
- **省电**：切到别的标签页、或打开伪装界面时会自动暂停画面推送，回来继续。
- **性能**：画面按面板尺寸 1:1 采集（不放大、不发虚），帧数据走二进制通道、在 Worker 里解码；滚动时自动降质换帧率，停手 350ms 恢复清晰。面板拉大后会重新采集，画面会短暂停顿一下。

限制：**没有声音**；不能像普通网页那样框选文字（可用阅读模式复制正文）。

### 浏览器窗口

需要视频/音频时用 **浏览器打开**：插件会拉起系统里的 Chrome 或 Edge，独立窗口、独立 profile。
需要本机已安装 Chrome 或 Edge。

### 书签与历史

- **收藏此页** 收藏当前页；本地小说的收藏是「这本书 + 这一章」，点开直接跳回该章。
- **历史** 记录访问过的页面，可在侧栏清空。

## 本地小说

侧栏 **本地小说 → 导入 txt**，完全离线阅读。

### 导入

- 支持 `.txt` / `.text` / `.md`，单本上限 **48 MiB**（UTF-8 约 2400 万字，GBK 约 2500 万字）。
- 编码自动识别：先按 UTF-8 解析，失败退回 GB18030（老 txt 多为 GBK）。
- 章节识别覆盖 `第123章` / `第0001章` / `第十二回` / `第 N 节` / `Chapter 12` / `卷一` /
  `序章·楔子·番外·大结局`。

### 书架与分卷

- 导入的书都在书架，点击切换；可单独移除。
- **分卷自动合并**：`书名_1.txt` / `_2` / `_3`（也认 `上/中/下`、`第N卷`、`Part 2`）会折成书架里的一条，
  目录是全书连续的章表，读到第 1 卷最后一章点「下一章」直接进第 2 卷。
- 缺卷不会阻断：某一卷文件丢了，其余各卷照常可读，只提示缺了几卷。

### 阅读

- 侧栏目录支持**虚拟滚动**，两千多章也不卡；当前章自动高亮并滚到可见处。
- 正文上方有章节下拉、`‹ 上一章` / `下一章 ›`，中间显示「第 n / m 章」。
- 每本书**独立记住进度**，来回切书都回到原处。
- 字体、字号、行高、页宽、配色、繁简转换与网页阅读共用同一套设置。

### 删除

书架条目上点删除即可移除；正文文件同时删除。

## 设置项

右上角 **设置** 分三页：

| 页签 | 内容 | 建议 |
|---|---|---|
| **阅读样式** | 字体、字号、行高、页宽、段距、首行缩进、配色（浅色/深色/跟随 DBX）、自定义 CSS | 中文小说常用：宋体、19–20px、行高 1.8–2.0 |
| **浏览器** | 用于「浏览器打开」的可执行文件与 profile | 默认自动探测 Chrome / Edge |
| **通用** | 繁简转换、伪装界面切换热键、显示位置 | 默认热键 `Escape` |

**自定义 CSS** 会追加到阅读视图，可覆盖任意样式；面板里会提示是否生效。

### 伪装界面

工作中不想被看到在看书时，按热键（默认 `Escape`）切到一个普通的数据表格界面，再按一次切回来。
热键可在「设置 → 通用」里改。

## 常见问题

**装不上，提示 `Plugin package must have a trusted Ed25519 signature`**
未签名包被拦。插件中心 → 设置 → 勾选「允许安装未签名开发包」再装。

**提示 `is incompatible: Plugin requires DBX >= …`**
插件要求的 DBX 版本高于你当前的版本。本插件要求 `>= 0.6.0`；若你看到更高的要求，
说明用的是旧构建，请安装 0.7.8 或更新版本。

**打开页面报 403 / 只拿到验证码页 / 一片空白**
目标站点反爬。常见原因是开了 VPN 或代理：关闭后重试，或改用**实时页面**。

**实时页面黑屏、点不动**
1. 确认系统有 WebView2 运行时（Windows 11 自带；Windows 10 通常随 Edge 安装）。
2. 首次打开需要几秒；若一直停在「正在启动」，退出实时再进一次。
3. 画面是全黑但上方有「实时渲染」标记，多半是页面自身加载失败，换**浏览器打开**验证。

**实时页面没有声音**
设计如此：实时页面只传画面。要声音用**浏览器打开**。

**实时页面有点卡**
滚动时会临时降质保帧率、停手自动恢复；把面板调小、或退出实时改用阅读模式，都会更流畅。

**文章里的图片是空白**
站点有防盗链且代理失败；用**整页模式**或**浏览器打开**查看原图。

**本地小说乱码**
先确认文件本身没损坏。插件会 UTF-8 → GB18030 依次尝试；仍有问题请附上文件编码信息提 Issue。

**目录太长、滚动卡**
已做虚拟滚动，只渲染可视区域。若仍卡，请告知章节数与文件大小。

## 隐私与权限

- **权限**：只用 `host.storage`（保存设置、书签、书库索引）、`host.events` 与 `host.binary`（实时画面的二进制帧通道）。不申请网络、文件系统、
  剪贴板权限。
- **网络**：由插件的原生 sidecar 直接访问你输入的网址（抓正文、取图片），图片在本地转成内联资源。
  **没有遥测、没有自建服务器、不向第三方上传任何内容。**
- **本地文件**：导入的 txt 写入插件自己的数据目录（`DBX_PLUGIN_DATA_DIR`），不上传、不联网。
- **实时页面**：使用独立的浏览器 profile，登录 Cookie 只存在本机。

## 已知限制

- **仅 Windows x64**：实时页面依赖 WebView2 与 CDP，macOS / Linux 无法使用。
- **实时页面无音频**，且不能框选文字。
- **需要登录/强验证码的站点**，阅读模式拿不到正文，必须用实时页面或浏览器窗口。
- 站点改版会导致选择器失效，可通过**站点预设**自行修正，或提 Issue。
- 「浏览器打开」需要本机已安装 Chrome 或 Edge。
